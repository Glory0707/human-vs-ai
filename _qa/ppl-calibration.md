# 句级困惑度标定（P3 句级困惑度，冻结零训练）

语料：AI gen-oos 四模型 vs 真人豆瓣/果壳（样本外问答集，`--sample 25`）。
方向 = AI 更顺滑（PPL 更低），AUROC < 0.5 时区分度取 1-AUROC。
PPL 口径见 human_vs_ai/ppl.py；复跑 `python tools/ppl_calibration.py --model <HF路径>`。

| doc 级特征 | Qwen3-0.6B-Base | Qwen3-1.7B-Base |
|---|---|---|
| median_ppl | 0.483（区分度 **0.517**） | 0.455（**0.545**） |
| mean_ppl | 0.367（**0.633**） | 0.343（**0.657**） |
| p10_ppl | 0.447（**0.553**） | 0.417（**0.583**） |
| AI/真人 median_ppl 中位 | 176.6 / 212.7 | 118.5 / 169.4 |

结论：**信号弱，且对规模响应平缓**——参数 ×2.8（0.6B→1.7B）最强特征区分度
仅 +0.024（0.633→0.657），仍远低于 0.70 信号线；按此外推，等比放大到"可用"
不现实。句级困惑度维持可选弱信号、默认关闭，不再挂"待更大模型重标"。
