# 对抗自评测：改写器当攻击者

日期：2026-09。工具：`tools/adversarial_eval.py`。语料：C-ReD
composition（claude-3.5-haiku / deepseek-v3 / gpt-4o / qwen-2.5 / qwen-3），
只攻击原文 ≥60 分的样本。规则开源的前提下，量化"照着建议规避"还能剩
多少区分度，并给出规则演化方向。

## 攻击者一：本项目改写器（750 篇）

服从改写建议的作者：删类删行、改类换候选文本（逐句成行喂给改写器——
AI 文本多为整段散文，整段喂只能得到方向提示，逐句才模拟真实规避路径）。

| 指标 | 改写前 | 改写后 | 变化 |
|---|---|---|---|
| 平均指数 | 94.1 | 94.1 | −0.0 |
| ≥60 分占比 | 100% | 100% | 0 |
| 词表层命中（均） | 2.44 | 2.39 | −2% |
| 统计层命中（均） | 0.67 | 0.68 | — |

解读：essay 场景的高分由**统计底盘主导**（C-ReD 作文的词表命中密度
高但文本覆盖率低），改写器的删/改候选主要覆盖公文/自媒体的行级套路，
对作文域几乎无招——分数纹丝不动。这不是攻击无意义，而是如实呈现：
**词表层规避不动统计主导的判定**。

## 攻击者二：LLM 洗稿（30 篇，doubao-seed-2.1-pro）

实战级对抗：把检测依赖的三件事（节奏/词表/排比）直接写进攻击
prompt，要求保留信息、打散节奏、删模板词——正是"用 AI 去 AI 味"
的真实场景。

| 指标 | 改写前 | 改写后 | 变化 |
|---|---|---|---|
| 平均指数 | 94.9 | 85.6 | −9.3 |
| ≥60 分占比 | 100% | **93.3%** | −6.7pp |
| 词表层命中（均） | 1.27 | 0.13 | **−89%** |
| 统计层命中（均） | 0.80 | 0.70 | −13% |

解读：LLM 攻击者把词表层几乎洗干净（−89%），平均指数也压低 9.3 分，
但 **93.3% 的样本仍超阈值**——句长节奏与词汇丰富度是全文统计属性，
LLM 逐句"写自然"时无法同时伪装分布。

## 结论

1. **评分底盘扎实**：两类攻击者（机械服从建议 / LLM 定向洗稿）都
   无法把高分样本洗到阈值以下，词表层被清空后统计层兜底。
2. **词表层是易规避层**（LLM 攻击下 −89%）：它的价值不在扛对抗，
   在逐句归因与改写建议——与"推断不是判定"的定位一致。
3. 规则演化方向：保持统计底盘权重；词表层随漂移监测（drift_monitor）
   迭代，不为对抗性加固牺牲可解释性。

## 复现

```
python tools/adversarial_eval.py --n 150                      # 攻击者一
python tools/adversarial_eval.py --attacker llm --n 6         # 攻击者二（需 API key 外读）
```
