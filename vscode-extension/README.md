# human-vs-ai · 中文 AI 味分析

可解释的中文 AI 味分析器：逐句指出哪里像模板、为什么像、怎么改。**风格提示，不是 AI 判定**——不输出"AI 率"，纯本地运行，文本不上传。

## 使用

1. 打开要检查的 txt / Markdown（docx/odt 走 CLI）
2. 命令面板（Ctrl+Shift+P）执行 **human-vs-ai: 分析当前文档** → 侧边出完整报告，正文里命中句画严重级波浪线
3. **human-vs-ai: 改写建议（个人口味）** → 逐句删/改/留建议，面板底部附清理稿折叠块

报告包含：AI 味指数（可拆解构成的综合风格分，非 AI 概率）→ 统计摘要 → 逐句发现（规则名 + 语言学解释 + 修改方向）→ 弱命中折叠。指数与统计鼠标悬浮可见校准口径。

## 场景

词表规则按文体分治，**选错场景会误报**：academic（学术）/ general（问答·自媒体）/ official（公文）/ essay（作文）/ news（新闻）/ review（短评）/ personal（个人口味）。默认 academic，可在设置里改。

## 隐私

纯本地分析，零网络调用，无账号。规则库与校准系数全部公开：[GitHub 仓库](https://github.com/Glory0707/human-vs-ai)。
