**T4.1 校准记录**：general@HC3 词表 AUROC 0.601（2023 语料对当代词表不友好，如实记录）；CV AUROC 0.763。方法论收获：词表必须 grep 语料验证（G-INTERACT 扩词表后命中率不动，grep 才发现表达频率为 0）；反向信号也是信号（"总之"17 倍差使 G-SAFE 生效、连接词密度反向使 general 不设 D-CONN）。

**T4.4 实现注记**：JS 引擎（web/engine.js）与 Python 包同构，`tools/check_web_consistency.py` 用 7 段固定语料 × 2 profile 逐字段 diff（findings/hints 全字段、stats 舍入 4 位；ttr 因浏览器无 jieba 口径不同而豁免，两端规则库均无 TTR 判定）。一致性测试首跑即抓到三处真实漂移：JS 正则缺 g 标志（replace 只删第一个标点）、引号嵌套处理缺 ASCII 引号奇偶逻辑、NaN 序列化差异。网页产物剥离维护者注（校准注/走查记录），CLI explain 保留完整解释——表现层各自决定，事实源唯一。
